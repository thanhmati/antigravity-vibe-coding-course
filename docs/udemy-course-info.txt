Course Title: Google Antigravity: Xây dựng AI Agent, AI App & Vibe Coding
Course subtitle: Vibe Coding and Agentic Workflow: Build AI Apps nhanh, scalable and production-ready
Course description:
Khóa học này giúp bạn hiểu và xây dựng AI Agent thực chiến – không chỉ dừng ở lý thuyết, mà đi từ mindset đến triển khai production.

Bạn sẽ bắt đầu từ:

Hiểu AI Agent là gì và sự khác biệt với AI truyền thống

Làm quen với Google Antigravity – nền tảng mới để build AI App

Nắm được cách Agent suy nghĩ, ra quyết định và hành động

Sau đó bạn sẽ đi sâu vào:

Model selection (Gemini, Claude, GPT-OSS)

Rules & Constraints để kiểm soát hành vi Agent

Workflows để tự động hóa quy trình

Agent Skills để kết nối API, database, hệ thống thực

Tiếp theo là các phần nâng cao:

Prompt Engineering cho AI Agents

Debug & tối ưu prompt

Context Engineering cho AI Agents

Multi-Agent Systems & Orchestration

Thiết kế Planner & Orchestrator

Tự động hóa các tác vụ với /schedule

Cuối cùng, bạn sẽ học cách:

Kết nối AI Agent với hệ thống ngoài qua MCP (Model Context Protocol)

Build workflow thực tế với MCP + Google Stitch

Setup môi trường production-ready

Sau khóa học, bạn có thể:

Build AI Agent cho sản phẩm thật

Tự động hóa workflow dev/business

Thiết kế hệ thống multi-agent phức tạp

Điểm đặc biệt của khóa học

Tập trung vào Agent Engineering thay vì AI theory chung chung

Hướng dẫn theo real-world use cases (không chỉ demo)

Áp dụng trực tiếp vào developer workflow & production systems

Kết hợp nhiều công nghệ mới: Antigravity, MCP, Multi-Agent


What is primarily taught in your course?
- Google Antigravity
- Vibe Coding
- AI Agents & Agentic AI

What will students learn in your course?
Hiểu AI Agent & Agentic AI mindset (how agents reason, plan, act)
Setup & build AI App với Google Antigravity từ A–Z
Làm chủ Core Concepts: Model, Rules, Workflows, Agent Skills
Chọn & sử dụng LLM (Gemini, Claude, GPT, OSS) đúng use case
Xây dựng Workflows automation & tích hợp API, database
Thiết kế Prompt Engineering + debug & optimize output
Phát triển Multi-Agent Systems (Orchestrator, Planner, /goal, /schedule)
Kết nối hệ thống qua MCP (Model Context Protocol)
Build real-world AI workflows với MCP + Google Stitch
Context Engineering – Giúp AI Agent "Nhớ" & Tối Ưu Token
Vibe Coding Dự Án Thực Tế – Từ Ý Tưởng Đến Sản Phẩm

What are the requirements or prerequisites for taking your course?
Có kiến thức cơ bản về programming (JavaScript / TypeScript)
Hiểu cách làm việc với API, HTTP, JSON
Không yêu cầu kiến thức về AI (sẽ được giải thích từ đầu)
Có tài khoản để sử dụng Google Antigravity (sẽ hướng dẫn setup trong khoá học)
Không yêu cầu kiến thức trước về AI Agent, MCP hay Multi-Agent Systems

Who is this course for?
Developer muốn ứng dụng AI vào sản phẩm thực tế
Lập trình viên muốn học AI Agent & Agentic Development từ zero → production
Backend/Frontend/Fullstack dev muốn tăng tốc độ build app với AI
Người đang làm sản phẩm muốn tích hợp AI Agent vào workflow hiện tại
Tech lead / founder muốn hiểu cách xây dựng AI-powered product
Những ai đã dùng ChatGPT nhưng muốn đi xa hơn (từ prompt → system)

Xen kẽ theory và demo thực chiến — ra khỏi section này với bộ Prompt Library cá nhân dùng được ngay.

[lecture] Prompt Engineering cho AI Agent là gì ?
- Description: Hiểu Prompt Engineering trong AI Agent và cách prompt ảnh hưởng đến cách agent suy nghĩ, quyết định và hành động. Khác biệt cốt lõi so với prompt chatbot thông thường: tại sao cùng một câu prompt cho ra kết quả đối lập giữa chatbot và AI Agent.

[lecture] Các lỗi phổ biến khi viết Prompt
- Description: Những lỗi thường gặp như prompt mơ hồ, xung đột instruction, thiếu context, over-prompting khiến agent trả lời sai, lặp vô hạn hoặc làm sai ngoài yếú muốn.

[lecture] Demo: Prompt tệ vs Prompt tốt — AI Agent phản ứng như thế nào ?
- Description: Demo sống động: cùng một task, 2 cách prompt khác nhau — AI Agent phản ứng hoàn toàn khác nhau. Học viên tự mắt chứng kiến hậu quả của prompt kém và hiệu quả vượt trội của prompt tốt trên Antigravity.

[lecture] Cách thiết kế Prompt hiệu quả (Role, Goal, Constraints, Output)
- Description: Framework 4 thành phần RGCO — Role, Goal, Constraints, Output — để thiết kế prompt có cấu trúc, rõ ràng và tái sử dụng được. Kèm template sẵn có cho từng loại task phổ biến: code generation, code review, UI design, bug fixing.

[lecture] Demo: Viết Prompt cho AI Agent từ Zero → Pro
- Description: Thực hành live trỮn Antigravity: bắt đầu từ prompt thô, áp dụng framework RGCO, tối ưu từng bước và so sánh output qua 3 use case thực tế: generate UI component, review code, debug lỗi phức tạp.

[lecture] Workshop: Xây dựng Prompt Library cá nhân
